# Skills

Each folder in this directory is a standalone Codex skill package with a `SKILL.md` file and any supporting references, scripts, examples, or assets it needs.

Install all skills by asking:

```text
Help me install Research Skills from https://github.com/Hyh2001/research-skills with Skills.
```

Install one skill by giving Codex the folder URL, for example:

```text
$skill-installer install https://github.com/Hyh2001/research-skills/tree/main/skills/paper-writer
```

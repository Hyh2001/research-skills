# Quality Checklist

Run this checklist before delivering a material-grounded course.

## Grounding

- Every lesson maps to one or more supplied sources or is clearly labeled `Supplemental`.
- Page, slide, figure, table, or section references are included only when actually inspected.
- Unreadable or partially extracted content is listed in `extraction-and-verification-issues.md`.
- External learning resources include URLs and a reason they fit the lesson.
- Unsupported claims are removed, marked `[unverified]`, or moved to a verification list.

## Curriculum Coherence

- Objectives are observable capabilities, not topic labels.
- The module order follows prerequisite dependencies.
- Each lesson teaches one coherent capability or prerequisite capability.
- The course includes a "what not to learn yet" section.
- The schedule matches the user's time budget.

## Learning Design

- Lessons ask for an attempt or prediction before explanation.
- New terms are defined at first substantive use.
- Worked examples include the reasoning, not only the result.
- Each important example has a contrast or boundary case.
- Practice matches the target capability.
- Support fades from worked examples to independent tasks.
- Answer keys are separate from learner-facing tasks.
- Review uses retrieval, not rereading.

## Resource Guide

- Recommended learning materials are not a link dump.
- Each external resource has a clear role: primary reading, supplemental explainer, practice source, or optional enrichment.
- There are no more than 1-3 external resources per lesson unless the user requested a bibliography.
- Fast-changing resources are checked for recency where possible.

## Final Response

Tell the user:

- where the course files are,
- what the generated course contains,
- what remains unverified or partially grounded,
- how to start studying,
- what to do next if they want the course expanded or converted to another format.
